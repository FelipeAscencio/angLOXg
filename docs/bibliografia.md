# 📖 Bibliografía y referencias

Durante el desarrollo de este proyecto y la fase de análisis de rendimiento, se utilizaron diversas implementaciones de referencia del lenguaje Lox (Provenientes principalmente del libro *Crafting Interpreters*) para realizar pruebas comparativas y validar el comportamiento de nuestro motor `angLOXg`.

## Repositorios y motores de referencia

* **[Crafting Interpreters](https://github.com/munificent/craftinginterpreters)** — Repositorio oficial del libro de referencia de Robert Nystrom (*munificent*), que incluye las implementaciones base de `jlox` (Java) y `clox` (C).
* **[plox](https://github.com/FdelMazo/plox)** — Intérprete de Lox escrito en Python por el docente/autor Francisco Del Mazo (*FdelMazo*).
* **[SlowLox](https://github.com/ArminKleinert/SlowLox)** — Intérprete de Lox orientado a objetos escrito en Ruby por Armin Kleinert (*ArminKleinert*).
* **[golox](https://github.com/aliwalker/golox)** — Intérprete de Lox escrito en Go por Ali Walker (*aliwalker*).
* **[Clojox](https://github.com/raghavio/Clojox)** — Intérprete de Lox implementado en Clojure por Raghav Sharma (*raghavio*).
* **[tslox](https://github.com/zlliang/tslox)** — Intérprete de Lox escrito en TypeScript sobre Node.js por Ziling Liang (*zlliang*).
* **[DotLox](https://github.com/TerrellAW/DotLox)** — Intérprete de Lox desarrollado en C# / .NET por Terrell Wright (*TerrellAW*).
* **[lox.rs](https://github.com/1ort/lox.rs)** — Intérprete de Lox implementado en Rust por *1ort*.

## Bibliografía general
